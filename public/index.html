Danh Sách Tools & Schemas MCP

Toàn bộ 11 công cụ MCP chuẩn hóa hỗ trợ tra cứu, trích xuất dữ liệu và tích hợp trợ lý AI thông minh:

tra_cuu_tthc_gia_lai
Alias: tthc_gia_lai
Tỉnh Gia Lai

Tra cứu chuyên sâu các Thủ tục Hành chính thuộc tỉnh Gia Lai. Bao gồm cấp tỉnh, cấp xã, các Sở ngành (Xây dựng, Nông nghiệp, Tài chính...), Hệ thống Chi nhánh VPĐKĐĐ (Pleiku, Chư Sê, Đak Đoa, An Khê, Ayun Pa, Kbang...), Ban Quản lý Khu kinh tế, Chủ tịch UBND tỉnh...

Tham số Schema 5 tham số
tu_khoa string tùy chọn
Tìm theo tên, mã hoặc nội dung nghiệp vụ.
ma_tthc string tùy chọn
Mã TTHC thuộc tỉnh Gia Lai để xem chi tiết ngay.
cap_thuc_hien enum mặc định: tat_ca
tat_ca, cap_tinh, cap_xa, cap_xa_va_tinh.
co_quan_thuc_hien string tùy chọn
Lọc theo cơ quan (Sở ngành, VPĐKĐĐ Pleiku, Chư Sê, UBND cấp xã...).
chi_tiet boolean mặc định: false
true để trích xuất đầy đủ hồ sơ, trình tự, căn cứ pháp lý.
MCP & REST
tra_cuu_tthc_noi_bo
Alias: tthc_noi_bo
TTHC Nội Bộ

Tra cứu chuyên sâu các Thủ tục Hành chính nội bộ trong hệ thống hành chính nhà nước. Gồm 2 nhóm: TTHC giữa các cơ quan hành chính nhà nước (liên thông, đa cơ quan/cấp) và TTHC nội bộ trong từng cơ quan (Bộ ngành, UBND cấp tỉnh, Sở ban ngành...).

Tham số Schema 7 tham số
tu_khoa string tùy chọn
Từ khóa tìm kiếm theo tên, mã hoặc nội dung nghiệp vụ nội bộ.
ma_tthc string tùy chọn
Mã TTHC nội bộ cụ thể (ví dụ: 6.006791, 5.003975) để xem chi tiết.
co_quan string tùy chọn
Cơ quan thực hiện hoặc công bố (Bộ Nội vụ, Bộ Công thương, UBND tỉnh...).
linh_vuc string tùy chọn
Lĩnh vực nội bộ (Khoáng sản, Thi đua khen thưởng, Công chức...).
cap_thuc_hien enum mặc định: tat_ca
tat_ca, cap_bo, cap_tinh, cap_xa.
nhom_noi_bo enum mặc định: tat_ca
tat_ca, giua_cac_co_quan, trong_noi_bo.
chi_tiet boolean mặc định: false
true để xem chi tiết đầy đủ hồ sơ, trình tự từng bước.
MCP & REST

TTHC Nội Bộ Gia Lai

Tra cứu chuyên sâu các Thủ tục Hành chính Nội bộ thuộc phạm vi tỉnh Gia Lai. Bao gồm các thủ tục cấp tỉnh, cấp xã, UBND tỉnh Gia Lai, Chủ tịch UBND tỉnh, các Sở ban ngành địa phương theo Nghị định số 385/2026/NĐ-CP (Khoáng sản, Đất đai, Nội vụ, Tài chính...).

Tham số Schema 7 tham số
tu_khoa string tùy chọn
Từ khóa tìm kiếm TTHC nội bộ tỉnh Gia Lai theo tên hoặc nội dung nghiệp vụ.
ma_tthc string tùy chọn
Mã TTHC nội bộ cụ thể (ví dụ: 5.003972, 5.003971) để xem chi tiết.
cap_thuc_hien enum mặc định: tat_ca
tat_ca, cap_tinh, cap_xa.
co_quan string tùy chọn
Cơ quan thực hiện tại Gia Lai (Chủ tịch UBND tỉnh, Sở TN&MT, UBND cấp xã...).
linh_vuc string tùy chọn
Lĩnh vực nội bộ (Địa chất khoáng sản, Đất đai, Thi đua khen thưởng...).
nhom_noi_bo enum mặc định: tat_ca
tat_ca, giua_cac_co_quan, trong_noi_bo.
chi_tiet boolean mặc định: false
true để xem chi tiết đầy đủ hồ sơ, trình tự từng bước.
MCP & REST
tra_cuu_theo_ma_tthc
Alias: chi_tiet_tthc
Chi Tiết Chuyên Sâu

Truy xuất toàn diện thông tin chi tiết chuyên sâu của TTHC theo mã (ví dụ: 6.006781) hoặc tên thủ tục. Cho phép trích xuất từng phân mục độc lập và xuất định dạng Markdown hoặc JSON cấu trúc sạch cho AI Agent.

Tham số Schema 3 tham số
ma_tthc string bắt buộc
Mã TTHC (ví dụ 6.006781) hoặc tên thủ tục.
phan_muc enum mặc định: tat_ca
tat_ca, ho_so, trinh_tu, chi_phi, thoi_han, can_cu_phap_ly.
dinh_dang enum mặc định: markdown
markdown (chuẩn đẹp) hoặc json (dữ liệu thô cho code).

Tham số Schema 3 tham số

limit number mặc định: 10
Số kết quả tối đa mỗi trang (1-50).
page number mặc định: 1

Gợi ý chuỗi thủ tục hành chính liên quan theo ngữ cảnh sự kiện đời sống & kinh doanh (sinh con, kết hôn, hộ kinh doanh, cư trú, y tế, mua bán nhà đất, thành lập doanh nghiệp...) hoặc liên thông cùng thủ tục gốc.

Số lượng thủ tục cần gợi ý (1-20).

markdown hoặc json.
